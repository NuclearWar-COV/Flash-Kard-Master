INSTALL AS AN ANDROID APP (no Android Studio needed)

1. Create a free GitHub account, make a new public repository.
2. Upload all files in this folder (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png).
3. Repo Settings > Pages > Deploy from branch > main / (root) > Save.
4. After ~1 minute open https://YOURNAME.github.io/REPONAME/ in Chrome on your phone.
5. Chrome menu (three dots) > "Install app" (or "Add to Home screen").

It then opens full screen with its own icon and works offline.
Cards are stored on the phone. Use Export now and then as a backup.
